# 实验预期、失败信号与探索方向

> 配套：`02_TASKBOOK.md`（验收/设计/清单）。任务书回答"是否达标"，本文档回答三件事：
> 1. **发表级预期**——什么样的数字才够 ICLR 门槛（含具体量级与推理依据）；
> 2. **失败信号**——什么信号出现应当早停/转向，而不是硬调参；
> 3. **可钻研方向**——哪些地方能挖出增量贡献与后续论文。
>
> 纪律：以下数字是**目标/预期区间**，不是已核实事实；每个阈值都给"why this value"的依据。真实结果一律以实测为准，达不到就诚实写。

## 一、发表级实验预期

发表级 = 审稿人能被三件事说服：**(A) 问题真实存在且被现有方法漏掉；(B) 我们的方法在因果指标上确有提升；(C) 提升能泛化、不是训练集过拟合或挑 seed。** 下面按这三层给可量化预期。

### 1.1 层 A：问题存在性（臂1 / 臂2 要跑出的"坏"数字）

| 指标 | 预期值 | 依据（why） |
|------|--------|-------------|
| 臂1 SFT 标准成功率 | 与公开 LIBERO-Goal 报告同量级（SmolVLA/OpenVLA 系在 70–90% 区间） | 证明基座本身能做任务，排除"根本不会做"的混淆 |
| 臂1 SFT 的 LSG（=hit−miss） | **≈0（\|LSG\|<5pp）**，且 hit 与 miss 都高 | 立论前提：高成功率但零语言敏感度=失聪。hit 高证明会做、miss 也高证明"错配指令照做"=没在听。对齐 LIBERO-Plus 2510.13626 |
| 臂1 指令交换重定向率 / language dropout | 重定向 **≤1/K+噪声**（K=3 约 ≤35%）；dropout 后 SR **几乎不降** | 忽略语言 → 换/去指令行为不变。dropout 不降是最直观的 Figure 1 证据 |
| 臂2a/2b RL 的 LSG | **仍显著低于臂4**（预期 <15pp） | 命根子：普通 RL 提成功率但不针对语言；paraphrase 增强抬 H(ℓ) 不抬 H(ℓ\|v)，同样修不好。若已很高→贡献被吃（见 F3）|

**发表底线**：臂1 必须出现"高 hit + 高 miss（即 LSG≈0）+ dropout 不降"的剪刀差。没有它问题不成立，全课题坍塌。

### 1.2 层 B：方法有效性（臂4 相对 2a/2b/3/5 的核心提升）

| 指标 | 发表级预期 | 依据 |
|------|-----------|------|
| 臂4 LSG（训练集，hit−miss） | **≥ +30pp**，其中 **hit 维持高（≤5pp 降）、miss 显著降** | 组内失聪期望奖励≤1/K 的下界→"必须分叉才拿优势"，理论上把 LSG 从≈0 拉到显著正。拆 hit/miss 防"整体变差刷差值" |
| 臂4 指令交换重定向率 | **≥60%**（K=3） | 高于随机 1/K(≈33%) 一倍以上才算"换指令真换行为" |
| 臂4 language dropout 掉幅 | 去语言后 SR **崩到 ≈1/K 或更低** | 真听懂的直接证据；与臂1"不降"形成对比图 |
| 臂4 标准成功率 | 相对臂1 **下降 ≤5pp**（理想持平或微升） | R12 约束，不能牺牲任务能力换敏感度 |
| 臂4 vs 臂3（CAST 数据侧） | 留出 LSG/重定向 **显著优于**（p<0.05, ≥3 seed） | 差分：CAST 标签仅 60–70% 准确，SFT 天花板受限；RL 用仿真真值无此天花板 |
| 臂4 vs 臂5（LangForce 损失侧） | 留出 LSG/重定向 **不劣于、且在 label-free/无需双分支上更简洁** | 若打平：主张"更简单、正交、可叠加"；若更优：主张"数据构造侧比损失侧更釜底抽薪" |

**发表底线（R15）**：**臂4 在留出集上 LSG 与重定向率同时显著优于臂2a/2b/3/5。** 单点故障，其余皆支撑。

### 1.3 层 C：泛化与稳健（把 delta 钉成"可信"而非"过拟合/关键词聋"）

| 维度 | 发表级预期 | 依据 |
|------|-----------|------|
| 留出泛化衰减 | 臂4 在 LIBERO-Plus / CALVIN 上 LSG 保持 **≥训练集的 60%** | 衰减过大=学的是训练指令 shortcut。60% 是"可信泛化"经验线 |
| **paraphrase 泛化（防关键词聋）** | 换说法/训练未见指令组合上，臂4 LSG 保持 **≥训练集的 50%** | **最关键的稳健性检验**：只在训练指令组合上赢=学到 "token→动作"（关键词聋）而非语义。paraphrase 也赢才是真杀手锏 |
| seed 稳定性 | ≥3 seed，臂4 LSG 的 std **≤ 均值的 1/3** | 方差过大=挑 seed，审稿人必挂 |
| 规模一致性 | OpenVLA-OFT-7B LoRA 上臂4 相对臂2a 的 LSG delta **同号且量级可比** | 证明非 450M 偶然。**注意只 2 个 scale 点，claim 写 "compatible with modern VLA architectures"，不画 scaling 曲线** |
| 成功率-语言权衡 | LSG vs SR 帕累托图，臂4 在 2a/2b/3/5 的**右上方** | 一张图同时回答"有效+不牺牲能力"，rebuttal 神器 |

### 1.4 "够 ICLR"的最小完整故事（一句话摘要模板）

> 我们（复用 LangForce/CAST 已提出的 Information Collapse 诊断）发现主流 VLA 高成功率却近零语言敏感度（臂1: succ 8x%, LSG≈0, dropout 后不降）；标准/ paraphrase 增强 RL 都不修语言（臂2a/2b: LSG 仅 +Xpp）；数据侧反事实 SFT 受限标签噪声（臂3）、损失侧 PMI 需双分支（臂5）；而对比式指令 GRPO 在**无需任何标签、不改损失**的情况下把 LSG 提到 +Zpp（Z≥30）、重定向率 ≥60%、dropout 后崩到 ≈1/K，且在 LIBERO-Plus/CALVIN/paraphrase 留出与 7B 规模一致成立，并可与 LangForce 正交叠加。

**加分项（非必需，显著提升接收概率）**：
- **组内下界 Proposition**（形式化"失聪策略组内期望优势=0，故只有语言依赖分量贡献正梯度"），对齐 CAST Lemma IV.1 / LangForce 的理论严谨度。
- **真机小样验证**（1–2 任务）：证明非纯仿真伪影。P4 可选。

## 二、失败信号（早停/转向判据，一次只改一处）

原则：区分"**方法错**"与"**工程错**"。工程错（harness/奖励回读/显存）修；方法错（信号不对）转向，不硬调参。每条给"信号 → 最可能机理 → 处置"。

### 2.1 P0 前置阶段的致命信号（go/no-go）

- **F0.1 对比组构造不成立**：LIBERO-Goal 无法锁定像素一致 s₀ + 切换目标谓词，且回退的程序化反事实也做不出"同图不同正确动作"。
  → 机理：方法的因果信号来源不存在。 → **处置：直接 no-go，换课题或改用其它支持该结构的基准（如 CALVIN 的多目标场景）。这是硬门。**
- **F0.2 奖励回读与官方 evaluator 不一致**（100 条抽样一致率 <100%）。
  → 机理：BDDL 谓词判定有 bug。 → 处置：工程错，修判定逻辑，不进 P1。参考 RA-LOOP 已踩过的 `set_state_from_flattened` 覆盖坑（评测器 reset 后又用 pruned_init 覆盖扰动的教训）。

### 2.2 立论级失败信号（触发即重估课题价值）

- **F1 臂1 没有剪刀差**：SFT 成功率就低（<50%），或 LSG 本身就显著为正（>15pp）。
  → 机理：要么基座不会做任务，要么这个数据集/基座**本来就不失聪**。 → 处置：换更"失聪"的设置（换基座/换任务子集），或承认在此设置下问题不成立、转向。**不可无视继续训臂4。**
- **F3 臂2a/2b 已经把 LSG 修好了**（普通成功率 RL 臂2a 或加同义指令增广的臂2b，其 LSG 接近臂4）。
  → 机理：普通任务成功率 RL（或仅靠同义指令增广）顺带修复了语言 grounding，我们的对比奖励没有独特贡献。 → **处置：这是最危险的信号。先确认臂2a 的组构造确实是"单指令"（没混入隐性对比），臂2b 只做同义改写、没引入互斥目标；若确认无误，则核心卖点崩，转向"分析为何普通 RL / 指令增广有时能修 grounding"作为分析型论文，或强化 CALVIN 长程/OOD 上二者的差距。**
- **F4 臂4 训练集 LSG 高但留出集塌到≈0**。
  → 机理：过拟合训练指令集，学的是指令-场景 shortcut 不是语言。 → 处置：加大指令多样性、检查留出集是否真不相交；若仍塌，说明对比奖励只教会"记住训练指令"，方法泛化性存疑，须在 method 里如实讨论并降低 claim。
- **F4b 关键词聋（keyword-deafness）**：臂4 在训练用的原始指令上 LSG 很高，但换成同义改写指令（paraphrase 留出集）后 LSG 或成功率骤降（保持率 <50%）。
  → 机理：模型学到的不是"理解语言语义"，而是把少数关键词（如物体名/方位词）当成场景 shortcut 的触发器——一种更隐蔽的伪 grounding。 → 处置：训练期就混入同义指令（对齐臂2b 的增广策略）；若混入后仍塌，说明对比奖励诱导的是词面匹配而非语义 grounding，须在 method/limitation 中如实披露，并把 paraphrase 保持率作为主表的必报指标而非附录。

### 2.3 训练稳定性信号（工程/超参级，可修）

- **F5 策略熵坍塌**（entropy<0.1 持续 ≥200 步）且成功率停滞。
  → 机理：GRPO 过早收敛到单一模式。 → 处置：触发防御性 shaping（监控触发项，不进 method）；加 KL 正则拉回 SFT 初始策略；必要时降 lr。
- **F6 组内奖励恒定**（一组 K 条 r 全 0 或全 1，std≈0，优势≈0）。
  → 机理：全 0 = 任务太难策略完全失败；全 1 = 任务太易或谓词判定过松。 → 处置：全 0→先确认基座能做该任务（回 T0.2）；全 1→收紧目标谓词或提高指令冲突度。**组内无方差 = 无学习信号，是 CI-GRPO 的特有死穴，须专门监控组内 r 的方差分布。**
- **F7 GRPO 训练发散/奖励震荡不收敛**。
  → 机理：GRPO 在该设置不稳。 → 处置：按 RLVLA（2505.19789，已核实 PPO>GRPO>DPO）回退 PPO，method 里说明选择依据。
- **F8 臂间不公平质疑**：臂3 用了远多于臂4 的有效交互/数据。
  → 机理：预算未对齐。 → 处置：按"等效交互次数"重新对齐（任务书 2.4），否则胜负无意义。

### 2.4 止损时间盒

- P0（第 7 天）：F0.1/F0.2 未解决 → no-go。
- P1（第 20 天）：F1 剪刀差不成立 → 停，重估设置。
- P2 中期（第 30 天）：臂4 训练集 LSG 仍 <+15pp → 大概率方法或组构造有问题，回查 F6，不硬堆算力。

## 三、可钻研 / 探索方向

分三档：**(甲) 主线内必做的深挖**（让当前论文更硬）；**(乙) 单独成篇的延展**（后续论文种子）；**(丙) 高风险高回报的开放问题**。

### 甲、主线内深挖（增强当前投稿）

1. **组内下界的理论化**：把"失聪策略组内期望奖励≤1/K"写成正式命题+证明，并推广到 soft 奖励/连续目标。对齐 CAST Lemma IV.1 的严谨度，是审稿人加分点。
2. **K 与组结构消融**：K=2/3/4/6 对 LSG 的影响；理论预测 K↑→失聪惩罚↑但样本成本↑，找帕累托点。这是"why this K"的直接答卷。
3. **指令冲突强度谱**：从"完全冲突（不同物体）"到"细粒度冲突（同物体不同放置）"到"近义指令"，画 LSG 随冲突强度的曲线，定位方法在何种语言差异上最有效。
4. **失聪的机制探针**：用 attention/梯度归因看训练前后语言 token 对动作的因果影响（做 causal mediation / 语言 token ablation），把"学会听语言"从行为指标坐实到内部机制。这是从"有效"到"可解释"的跃迁。
5. **奖励来源消融**：稀疏 0/1 vs 轻量 shaping vs 学习型奖励模型，验证"无标签稀疏奖励足够"的 claim。
6. **与 LangForce 的正交组合（臂6，主线内近期项）**：LangForce（2601.15197）在损失侧用双分支条件 PMI 修失聪，我们在奖励+数据构造侧修，两者机理正交。近期落地为臂6 = CI-GRPO 对比奖励 + LangForce PMI 辅助损失联合训练，检验 LSG/重定向率是否叠加增益。这是把"最强并发威胁"转成"可组合的互补证据"的关键一手——即使单独 delta 不够惊艳，正交叠加的协同效应本身就是 method 的独立卖点。须先在 LIBERO 上复现臂5（LangForce 单独）作为对照锚点。

### 乙、单独成篇的延展（后续论文种子）

6. **课程式对比组**：按冲突强度/任务难度做 curriculum，先易后难，可能显著提样本效率——独立的"高效语言 grounding RL"故事。（编号沿用；与甲-6 不冲突，甲-6 为主线内近期项，此处为后续独立选题）
7. **跨具身/跨基准迁移**：在 LIBERO 上学到的"语言敏感策略"能否零样本迁移到 CALVIN/SimplerEnv/真机，检验语言 grounding 是否是可迁移能力。
8. **对比组自动挖掘**：用 VLM 自动从大规模场景里挖"同图不同指令不同目标"的三元组，去掉对 BDDL 谓词的依赖，扩展到无仿真谓词的真机数据——这是把方法从仿真推向 in-the-wild 的关键，独立价值大。
9. **语言敏感度作为通用诊断协议**：把 LSG/重定向率标准化成一个可插拔的 VLA 语言 grounding 评测套件（对标 LIBERO-PRO 2510.03827 的协议化思路），benchmark 类论文。

### 丙、高风险高回报开放问题

10. **失聪的"数据配方"根因**：系统性地改变训练数据里"指令-场景互信息"，验证 P(a|img)≈P(a|img,instr) 假设是否是失聪的**充要**条件——若成立，可提出"数据侧免疫"方案（造训练数据时就注入对比），从源头预防，而非事后 RL 修补。
11. **对比奖励 vs 表征对齐的统一视角**：把 CI-GRPO 与 GRIF（2307.00117）式语言-目标表征对齐放到同一理论框架，问"对比在动作层（我们）还是表征层（GRIF）更本质"。
12. **多模态失聪的推广**：语言只是被忽略的模态之一（RobustVLA 2510.00037 指动作最脆）；能否把"对比组"推广到强制模型使用**任何**被忽略的条件模态（深度/触觉/历史帧），成为通用的"模态 grounding RL"框架。

### 优先级建议

- 投稿前必做：**甲-1、甲-2、甲-4**（理论命题 + K 消融 + 机制探针），这三样把论文从"实验报告"升级到"有机制解释的贡献"。
- 若主线 delta 显著且时间有余：补 **甲-3、甲-5、甲-6**（冲突强度谱 + 奖励来源消融 + LangForce 正交组合）。甲-6 若协同增益显著，可从"锦上添花"升级为主表卖点。
- 后续独立论文优先级：**乙-8（真机/自动挖掘）> 乙-9（诊断协议）> 乙-7（迁移）**。
