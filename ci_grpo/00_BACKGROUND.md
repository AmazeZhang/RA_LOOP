# 背景与动机：VLA 的"语言失聪"问题与对比式指令强化学习

> 项目代号：**CI-GRPO**（Contrastive-Instruction GRPO）
> 目标会议：ICLR 2027（约 60 天窗口，起点 2026-07-27）
> 算力约束：7×RTX 4090（168 GB，无 A100/H100），可按需短租单张 80 GB 卡
> 文档语言：中文；所有外部事实附 arXiv 链接与核实等级（见 `01_RELATED_WORK.md`）

---

## 1. 一句话问题陈述

当前主流视觉-语言-动作模型（VLA）在标准操作基准上"看起来"能听懂语言指令，但大量证据表明它们实际上**主要依赖视觉场景与物体布局来选择动作，几乎忽略语言指令本身**。我们称之为 VLA 的**语言失聪（language deafness）**。本项目提出用一种**对比式指令强化学习**目标，从因果上强制策略把动作条件在语言上，并用一套**可证伪的语言敏感度指标**量化"到底听没听懂"。

---

## 2. 现象：三条已核实的硬证据

以下三条为 Tier A（已逐一 fetch 原文核实，详见 `01_RELATED_WORK.md`）：

**(a) 换指令、行为不变。** LIBERO-Plus（arXiv 2510.13626，CVPR 2026）系统性扰动 LIBERO 的七个维度，发现在**语言指令维度**上，把指令替换/打乱后，SOTA VLA 的成功率几乎不下降——即模型的动作与语言几乎无关；同一工作还显示视角扰动能把成功率从 95% 打到 <30%，说明模型高度依赖视觉捷径。

**(b) 破坏指令，成功率仍不崩（或按"场景先验"崩）。** LIBERO-PRO（arXiv 2510.03827）设计了受控的"损坏指令"协议：当指令被替换为无意义/冲突文本时，一个真正条件于语言的模型应当失败，但被测 VLA 在很多设置下仍按场景先验完成任务，暴露出评测分数虚高（部分设置从 90% 名义成功率掉到 0% 才反映真实语言依赖）。

**(c) 动作模态最脆弱、grounding 是幻觉。** RobustVLA（arXiv 2510.00037）在多模态扰动下发现动作输出对输入扰动最敏感，语言 grounding 在分布外基本失效——"能听懂"更多是训练集共现统计而非真正的因果绑定。

结论：**"VLA 听懂语言"在标准基准上是一个被高分掩盖的幻觉。** 这既是一个被反复观测、但尚未被 RL 后训练系统性解决的真问题，也是一个 ICLR 级别审稿人能立刻共情的痛点。

## 3. 根因分析：为什么模仿学习学不出语言条件

**互信息（MI）论证。** 在 LIBERO / BridgeData 这类数据里，指令与场景高度耦合：一个"把碗放到盘子上"的指令，几乎总是配一个碗和盘子已经在画面里的初始场景。于是对策略而言：

```
P(action | image) ≈ P(action | image, instruction)
```

也就是说，**给定图像后，指令几乎不提供额外信息**。用条件熵表述更精确：在这类数据里 H(ℓ|v)≈0（看到画面就几乎能猜到指令），于是条件互信息 I(ℓ;a|v)→0。行为克隆（BC）的交叉熵损失对"是否使用语言"没有任何梯度压力——模型只要把动作条件在图像上就能最小化训练损失，语言分支自然退化成装饰。

**这个诊断是已发表的共识，不是本项目的新颖点。** 两篇工作已独立给出同一根因的形式化，引用时必须如实归属：
- **LangForce（arXiv 2601.15197，ICML 2026，Tier A 已核实）** 称之为 **"Information Collapse"**：指令可被视觉预测 → 语言-动作条件互信息消失 → 模型退化成"忽略语言约束的 vision-only 策略"，在 OOD 下失败。
- **CAST（arXiv 2508.13446）** 在 Lemma IV.1 给出同类互信息形式化：语言对动作的条件互信息接近 0 时，任何最大似然目标都无法迫使模型利用语言。

**本项目的新颖性因此收窄到"解法侧"，不在诊断。** 要修复语言失聪，必须**人为把 H(ℓ|v) 从 ≈0 抬高到 log K**（同一 v 下让 K 条指令等概率出现），让 `P(action|image)` 不再等于 `P(action|image,instruction)`。这是比"从损失函数侧强行拉互信息"更釜底抽薪的数据构造侧干预。目前有三条互不相同的路：

1. **数据侧（SFT）**：合成反事实标签，即对同一场景、不同指令，人工/大模型标注出不同的正确动作。CAST 走的就是这条路（Gemini 2.5 Pro relabel，标签准确率 60–70%，纯 SFT，真机导航为主）。缺点：标签质量天花板低、需要外部大模型、无法保证动作最优。

2. **损失侧（objective）**：不改数据，改目标函数直接惩罚视觉捷径。LangForce 走这条路（双分支估计 vision-only 先验 p(a|v) 与语言条件后验 π(a|v,ℓ)，优化二者的条件 PMI；SimplerEnv/RoboCasa，OOD +11.3%）。与本项目**正交**，理论上可叠加（见第 7 节与任务书臂 5/6）。

3. **奖励侧 + 数据构造侧（RL，本项目）**：不造标签、不改损失，而是**构造对比式 rollout 组**——同一初始视觉状态 s₀，配 K 条互相冲突的指令 ℓ₁…ℓ_K（分别指向不同目标 g₁…g_K）；只有当 rollout 达成的目标与**当前这条指令**匹配时才给奖励 r=1。如果策略忽略语言，它对一组里 K 条指令会输出几乎相同的动作，期望成功率 ≤ 1/K，被 GRPO 的组内相对优势狠狠惩罚；只有真正读懂语言、按指令分叉动作，才能拿到高组内优势。

**为什么选 RL 路线：** (i) 无需外部大模型标注，规避 CAST 60–70% 标签噪声天花板；(ii) 奖励来自仿真器的真实目标判定（BDDL 谓词），是"无标签但有 ground-truth 判定"的干净信号；(iii) GRPO 的组内相对优势天然编码"对比"，与"把 H(ℓ|v) 抬到 log K"的组结构同构；(iv) 与 LangForce 的损失侧干预正交，可组合。

## 4. 核心方法概览（细节见任务书）

**CI-GRPO（Contrastive-Instruction GRPO）。**

- **组的构造**：group = 同一初始视觉状态 s₀ × K 条冲突指令 {ℓ_k}，每条指令对应一个可由仿真器判定的目标谓词 g_k。构造须满足三条硬约束（详见任务书 2.2）：(a) 所有 g_k 在 s₀ 下**都可达且未满足**；(b) 任意两目标**互斥** `∀i≠j: g_i(traj)∧g_j(traj)=False`，防奖励污染；(c) 任意两指令的最优轨迹**在早期就分叉**（用前 N 步 DTW 距离筛选），否则共享前缀上的组内优势恒为 0、梯度只砸在末段，稀疏奖励+长 horizon 下训不动。
- **奖励**：r_k = 1 当且仅当 rollout 末态满足 g_k（当前指令对应目标），否则 0。可加轻量 shaping（可选，默认关闭，防御性触发）。
- **优化**：GRPO 组内相对优势 Â_k = (r_k − mean(r)) / (std(r)+ε)，标准 PPO-clip 更新，observation masking（只对 action token 计 loss）。
- **失聪的数学下界（可形式化为 Proposition）**：若策略与语言无关 π(a|v)，则组内所有 r_k 同分布，mean≈1/K，组内期望优势=0，**不产生任何梯度更新**（注意是归零而非爆炸，分母有 ε 兜底）；只有 π(a|v,ℓ) 中真正依赖 ℓ 的分量才能贡献正梯度。
- **定位**：CI-GRPO 是 **post-training 阶段**，不是 from scratch——须先有一个 clean SR≈40–60% 的 BC/SFT base（即臂 1）产生正样本，否则组内全 0、std=0 学不动。

## 5. 可证伪的评测指标（本项目的科学命根子）

1. **语言敏感度差距 LSG（Language Sensitivity Gap）**——主指标，须拆成两项防止"整体变差也显得赢"：
   `LSG = LSG-hit − LSG-miss`，其中 LSG-hit = succ(正确指令)（越高越好，证明执行力没坏），LSG-miss = succ(错配指令，同场景)（越低越好，证明会"拒绝"不匹配指令）。只有 **hit 维持高 且 miss 显著降** 才算真听懂。可类比因果推断的 **ATE（把 instruction 当 treatment）**，LSG 即指令这一 treatment 对成功的平均处理效应。

2. **指令交换重定向率（instruction-swap redirection rate）**
   同一 s₀ 下把指令从 ℓ_i 换成 ℓ_j，测量策略行为切换到 g_j 的比例。衡量"换指令是否真换行为"（行为层可控性，比结果层成功率更狠）。

3. **language dropout 探针**（Figure 1 级、零重训）：推理时把语言 token 置零/换 [MASK]，看 SR 掉多少。失聪模型几乎不变；真听懂的模型应崩到 ≈1/K 或更低。须与"错配指令"指标配对呈现（MASK 属 OOD 输入，单看不够严谨）。

4. **标准成功率**（sanity，不能掉太多）。

5. **留出泛化 + 关键词聋防御**：不仅测 LIBERO-Plus 语言轴 + CALVIN 长程指令，还须测 **paraphrase 泛化**（训练"put apple on the left"，测试"place the fruit to the west side"）与**训练未见的指令组合**。若只在训练分布内指令组合上赢，说明学到的是 "token→动作" 关键词映射（"关键词聋"），不是语义理解；paraphrase 也赢才是真杀手锏。

## 6. 对照实验矩阵（立论根基）

核心四臂（必做）+ 两个强化臂（视时间）：

| 臂 | 名称 | 作用 |
|----|------|------|
| 1 | SFT baseline | 复现"忽略语言"（LSG≈0），确立问题存在，并作为 RL 的 base |
| 2a | 任务成功率 RL（标准 GRPO，单指令组） | RLVLA 式设置，检验普通 RL 是否顺带修好 LSG——预期不能 |
| 2b | paraphrase 增强 RL（同 goal 多种说法） | **更强**的单指令基线：语言侧堆数据但无冲突组结构。理论上仍不改 H(ℓ|v)（换说法都指向同一动作），预期仍修不好——赢它才证明"必须要冲突组结构" |
| 3 | CAST 式反事实 SFT（适配到仿真） | 最强 incremental 对手：数据侧解法 |
| 4 | **CI-GRPO（本项目）** | 奖励+数据构造侧解法，须在留出集上 LSG / 重定向率显著优于臂 2a/2b/3 |
| 5 | LangForce 式损失侧 PMI（适配到 LIBERO） | 损失侧最强对手；也用于验证正交性 |
| 6 | **CI-GRPO + LangForce PMI（叠加，stretch）** | 若能叠加涨点→同超两条 SOTA；若不能→说明攻击同一 bottleneck，也是 interesting finding |

**立论逻辑**：臂 1 证明问题存在；臂 2a/2b 证明标准 RL 与语言侧数据增强都修不好（否则我们没贡献）；臂 3 是数据侧最强基线，臂 5 是损失侧最强基线；臂 4 若在**留出**语言泛化上胜 2a/2b/3/5，则证明"对比式奖励"是修复语言 grounding 的更优路径；臂 6 探索与 LangForce 的正交叠加。任一环节失败都会诚实写入论文，不做包装。

## 7. 与现有工作的关键差分（详见 novelty-check）

- **vs LangForce（2601.15197，ICML 2026，最强并发威胁）**：LangForce 与本项目**共享同一诊断**（Information Collapse = 语言失聪），但解法族不同——LangForce 是**损失侧**（双分支 + 条件 PMI 惩罚，改目标函数，不改数据）；本项目是**奖励+数据构造侧**（构造冲突指令组 + 无标签 RL）。两者**正交、理论可叠加**（臂 6）。**关键防线**：(i) 诊断不能算我们的新颖点，须显式引用 LangForce/CAST；(ii) 我们的差异化在"label-free 仿真真值奖励 + 把 H(ℓ|v) 抬到 log K 的组结构 + 因果行为指标（LSG-hit/miss、重定向率、language dropout）"，这些 LangForce 都没有；(iii) LangForce 在 SimplerEnv/RoboCasa，我们在 LIBERO，跨基准数字不可直接并列，臂 5 是把它**适配到同一 LIBERO 协议**下的公平复现。
- **vs CAST（2508.13446，最强 incremental 威胁）**：CAST = SFT + 合成动作标签（60–70% 准确）+ 真机导航/操作 + 无 swap 指标；本项目 = 无标签 RL + 仿真 + 因果语言指标（LSG/重定向率）。方法族、信号来源、评测协议三者均不同。
- **vs RLVLA（2505.19789，"RL 已经有用"威胁）**：RLVLA 用任务成功率 RL 提升整体性能，但**不针对语言 grounding，也不含冲突指令组**；本项目的臂 2a 正是 RLVLA 式设置，我们要证明它修不好 LSG。
- **vs Knowledge Insulation（2505.23705，相关但非直接竞品）**：讲的是训练时隔离 VLM backbone 保知识迁移，与语言 grounding 不直接相关，仅作 VLA post-training 相关工作引用。
- 其余（GRAPE / VLA-RL / RIPT-VLA / TGRPO 等）均为"任务成功率"导向的 RL 后训练，无一构造"同场景冲突指令"的对比组，也无语言敏感度指标。

## 8. 可行性与算力现实

- **主力基座**：SmolVLA-450M（arXiv 2506.01844，Apache-2.0），单张 4090 可全参数训练，用于主力扫参与四臂对照。
- **规模确认**：OpenVLA-OFT-7B（arXiv 2502.19645）LoRA，单张 80 GB 卡最干净（按需短租 ~$100/run）。全参数 GRPO 需 8×80 GB（SimpleVLA-RL 路径），本项目**不做满血复现**。
- **RL 框架**：veRL / GRPO；参考 SimpleVLA-RL（github PRIME-RL/SimpleVLA-RL，MIT，group-by-uid 现成）与 RIPT-VLA（github Ariostgx/ript-vla，LoRA，注意无 license 文件，需邮件确认授权）。
- **基准**：LIBERO / LIBERO-Goal / LIBERO-Object（MuJoCo，单卡可跑）+ CALVIN 长程泛化。瓶颈是"单卡 80 GB 单元"而非总显存。

**结论**：算力不是瓶颈，7×4090 足以支撑 SmolVLA 主力路线；OpenVLA-OFT-7B 规模确认可短租解决。真正的风险在方法能否在**留出**语言泛化上跑出正 delta，这正是四臂对照要回答的。
